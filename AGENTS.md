## Project
- LF Creative marketing site: Vite 8, React 19, react-router-dom 7, plain CSS per component. No TypeScript.
- Routes: /, /portfolio, /portfolio/:category, /booking, /services/:slug (photo, video, marketing, webdesign), /profile/:slug.
- Layout: src/pages (routes, lazy loaded in App.jsx), src/components, src/data (team, services, booking), src/lib, src/services (Supabase and R2 access).
- Commands: npm run dev, build, lint. Lint has known errors outside this work (Booking.jsx, calendarService.js, PortfolioGrid.jsx).
- Do not edit the booking flow (src/pages/Booking.jsx) unless asked.

## Conventions
- Fonts are declared once in src/index.css: KH Interference (300, 400, 700), Figtree and Inter via Google Fonts.
- Section style: black background, faded 1px lines (rgba white 0.25), KH Interference bold uppercase headers.
- Team data lives in src/data/teamData.js and service data in src/data/servicesData.js. Pages read from these.
- Nav items come from the Supabase nav_items table. The Navbar renders Services first, then the items, then the home button.
- Cards use SpotlightCard with the shared preset in src/components/spotlightPreset.js.
- Third party components pasted from React Bits (SpotlightCard, Lanyard, ParticleText) are kept as provided. Do not refactor them.

## Performance
- QualityProvider sets data-quality (high, medium, low) on the html element from device signals and measured FPS.
- Degrade visuals only through src/quality.css or useQualityTier. Never hide content.
- Small images use heavily compressed WebP variants. Originals load only in previews.

## Media (Cloudflare R2, VITE_MEDIA_URL)
- Portfolio: originals at portfolio/<category>/<file>. Variants thumb (800px) and full (2000px) are generated by npm run process:portfolio, which also rewrites portfolio/manifest.json.
- Dome gallery: originals at domegalleryCollection/<file>. Tiles (320px, quality 30) are generated by npm run upload:dome and referenced with a version query (TILE_VERSION in DomeGallery.jsx) to bypass stale CDN cache.
- Do not run npm run upload:portfolio. It builds the manifest from a local folder and would overwrite the live one.
- Scripts write to the production bucket. Ask before running them with --force.
